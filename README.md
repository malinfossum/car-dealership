# car-dealership

Pair programming exercise (Week 4 of Emne 3 at Get Academy). A console app for a car dealership — inventory of cars, filtering by year range and mileage, and customer purchases that transfer ownership from dealer to customer. Built with [@HansN-92](https://github.com/HansN-92).

## Requirements

.NET 10 SDK — [download from Microsoft](https://dotnet.microsoft.com/download).

## Run

```powershell
dotnet run
```
